# راهنمای نصب و انتشار

1. ZIP را Extract کنید.
2. همه‌ی فایل‌ها و پوشه‌های داخل بسته را مستقیم در ریشه‌ی شاخه‌ی انتشار مخزن کپی کنید. از ایجاد پوشه‌ی تو‌در‌تو خودداری کنید.
3. GitHub → Settings → Pages → Build and deployment را روی Deploy from a branch بگذارید.
4. شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کنید.
5. منتظر پایان انتشار بمانید و آدرس GitHub Pages مخزن را باز کنید.

تمام ارجاع‌های CSS، JavaScript و favicon نسبی‌اند. فایل‌ها باید همراه HTMLها بمانند. این بسته backend ندارد.
