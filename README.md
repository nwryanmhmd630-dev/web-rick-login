# Webric Ultra Auth

قالب نمایشی فارسی و راست‌چین برای صفحات ورود، ثبت‌نام، بازیابی رمز و پنل دمو. این مخزن نسخه‌ی **استاتیک و ایمن برای GitHub Pages** است، نه سامانه‌ی احراز هویت.

> **مهم:** فرم‌های ورود، ثبت‌نام و بازیابی فقط ظاهر را نشان می‌دهند. ورودی‌هایشان غیرفعال‌اند و هیچ اطلاعاتی دریافت، ارسال یا ذخیره نمی‌شود. اطلاعات واقعی وارد نکنید.

## صفحه‌ها

- `index.html`: معرفی و پیوند به صفحه‌ها.
- `login.html`, `register.html`, `reset-password.html`, `verify-code.html`, `set-password.html`: پیش‌نمایش‌های ایستا، بدون ارسال فرم.
- `demo.html`: نمونه‌های ظاهری.
- `admin.html`: پنل نمایشی عمومی؛ هیچ احراز هویت یا تغییر تنظیمات واقعی ندارد.

## اجرا و انتشار در GitHub Pages

1. در مخزن، شاخه‌ی `main` و پوشه‌ی ریشه (`/`) را به‌عنوان منبع GitHub Pages انتخاب کنید.
2. فایل `index.html` و پوشه‌های `css/`, `js/`, `fonts/`, `assets/` باید همگی در ریشه‌ی شاخه باشند.
3. نشانی سایت: `https://nwryanmhmd630-dev.github.io/web-rick-login/`.
4. مسیرها نسبی‌اند و زیرمسیر پروژه را پشتیبانی می‌کنند. فایل `.nojekyll` نیز در ریشه قرار دارد.

## ساختار منبع

- `css/`: توکن‌های رنگ، پایه، اجزا، صفحه‌های احراز هویت، پنل دمو و واکنش‌گرایی.
- `js/`: تنظیمات پیش‌فرض غیرحساس، تم، آیکون‌ها و رفتار نمایشی.
- `fonts/fonts.css`: فونت‌های سیستمی؛ بدون CDN یا فونت خارجی.
- `assets/icons/`: favicon و اسپرایت SVG.

## امنیت و استفاده‌ی عملی

GitHub Pages محتوای ایستا میزبانی می‌کند و نمی‌تواند ورود امن، ثبت‌نام، OTP یا بازیابی رمز فراهم کند. برای این کار به بک‌اند امن نیاز است؛ رمزنگاری، محدودیت تلاش، نشست‌های امن و مدیریت بازیابی باید سمت سرور انجام شوند. کلیدهای API و اطلاعات حساس را هرگز در مخزن عمومی نگذارید.

`admin.html` عمومی است و فقط یک دموی نمایشی است؛ پیش از استفاده‌ی عملی حذفش کنید یا آن را پشت احراز هویت سمت سرور قرار دهید.
