# وب‌ریک | قالب تجربه‌ی ورود فارسی

نسخه‌ی تازه، مستقل و از صفر ساخته‌شده برای GitHub Pages. فارسی و RTL، واکنش‌گرا، بدون کتابخانه و CDN خارجی؛ رنگ‌ها و تم در تمام صفحات قابل تغییرند.

## انتشار روی GitHub Pages

محتویات همین پوشه را در ریشه‌ی مخزن قرار دهید، نه خود پوشه‌ی `webric-v4`. مسیرهای دارایی‌ها نسبی هستند و زیرمسیر یک مخزن GitHub Pages را پشتیبانی می‌کنند. سپس در مخزن به **Settings → Pages** بروید و شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کنید. فایل `index.html` باید در ریشه‌ی انتشار باشد.

## صفحات

- `index.html`: معرفی و دسترسی به بخش‌ها
- `login.html`: پیش‌نمایش ورود و تب ثبت‌نام
- `register.html`: چیدمان ثبت‌نام
- `reset-password.html`: گردش نمایشی سه‌مرحله‌ای
- `demo.html`: نمونه‌ی تعامل و تغییر تم
- `admin.html`: پنل شخصی‌سازی رنگ، گردی و شیشه

## نکته‌ی امنیتی مهم

این بسته عمداً رمز عبور یا اطلاعات ورود را دریافت یا ارسال نمی‌کند. کنترل‌های احراز هویت، ایمیل، OTP و OAuth فقط نمونه‌ی بصری هستند و به سرویس واقعی وصل نیستند. GitHub Pages میزبانی ایستا است؛ برای محصول واقعی، فرم‌ها را به بک‌اند امن متصل کنید و هرگز کلید محرمانه را در فایل عمومی قرار ندهید. `localStorage` فقط برای ترجیحات ظاهری مانند تم و رنگ استفاده می‌شود.
